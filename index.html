Known Limits
Shell commands are asked, never denied Shell text can be respelled in ways no regex rule matches. Path or command deny rules on shell tools (Bash, PowerShell, Monitor) act as ask so a human confirms.
Injection phrases are logged, not blocked Untrusted tool outputs (WebFetch, WebSearch, MCP reads) are scanned for 6 prompt-injection markers and flagged in the audit log, never silently dropped.
What Isolation adds (and its tripwire) Enabling "isolation": true in policy.json uses Claude Code's OS sandbox to block shell reads of secret paths outright. If a project setting widens the sandbox, the isolation tripwire refuses every shell call.
